# Финальный ролик: раскадровка

Раскадровка финального ролика праздника «Главный банковский день» в движении. Семь вариантов, каждый вырос из своего архетипа бренда. Рекомендуем «Сцену после титров».

Смотреть: https://denismarsgpt-glitch.github.io/final-video-storyboard/

Ссылка на отдельный вариант: добавь в конец адреса `#after-credits`, `#everyperson`, `#matchmaker`, `#translator`, `#pioneer`, `#athlete` или `#scientist`.

Цифры условные. Кадры схематичные: шрифт, цвет и графику ленты делает дизайнер. Страница нужна, чтобы согласовать смысл, порядок кадров и тексты на экране.

Вся страница в одном файле `index.html`: canvas и обычный JavaScript, без сборки и зависимостей. Шрифты с Google Fonts.
