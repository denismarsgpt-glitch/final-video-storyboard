# Финальный ролик: раскадровка

Раскадровка финального ролика праздника «Главный банковский день» в движении. В работе черновик финального дизайна: «Стрелка спасибо» в версии дизайнеров. Рядом семь исходных вариантов, три лучших с короной.

Смотреть: https://denismarsgpt-glitch.github.io/final-video-storyboard/

Ссылка на отдельный вариант: добавь в конец адреса `#matchmaker-design`, `#after-credits`, `#everyperson`, `#matchmaker`, `#translator`, `#pioneer`, `#athlete` или `#scientist`.

Цифры условные. Кадры собраны в стиле титров праздника: цвета, шрифт Onest, панели, плашка «отличных» и чип «Сейчас в титрах». Движение схематичное, финальную анимацию делает моушн-дизайнер. Вместо логотипа банка стоит заглушка.

Вся страница в одном файле `index.html`: canvas и обычный JavaScript, без сборки и зависимостей. Шрифт Onest с Google Fonts.
